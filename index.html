Amalgame

Centre de communication personnel — textos, MMS et courriels au même endroit.

Amalgame est une application Android que je développe pour mon propre usage. Elle regroupe les textos, les messages avec photos ou documents (MMS) et les courriels Gmail dans une seule file d'attente, pour que rien ne se perde entre plusieurs applications de messagerie.

Ce que fait l'application

  • Affiche les courriels non lus de ma boîte de réception Gmail dans la même file que mes textos.
  • Permet de répondre à un courriel ou d'en rédiger un nouveau, avec pièce jointe et mise en forme.
  • Garde les conversations sur mon téléphone, dans la base de données de l'application.

Accès à Gmail

Pour afficher et envoyer des courriels, l'application demande l'accès à mon compte Gmail par la connexion officielle de Google (OAuth). Les données restent sur mon appareil. Elles ne sont ni vendues, ni partagées, ni envoyées à un serveur. Le détail est dans la politique de confidentialité.

Usage et distribution

Amalgame n'est pas distribuée au public : elle n'est disponible sur aucun magasin d'applications et n'est utilisée que par son développeur et quelques proches invités.
